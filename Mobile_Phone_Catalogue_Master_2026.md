# 8. MASTER CATALOGUE DATA RULES

Every product must follow:

`Brand → Family → Series → Model → Network → Storage → RAM`

Examples:

- `Apple → iPhone → iPhone 17 Pro Max → 5G → 1TB`
- `Samsung → Galaxy S → S26 Ultra → 5G → 1TB → 16GB`
- `Google → Pixel → Pixel 11 Pro XL → 5G → 512GB → 16GB`
- `TECNO → CAMON → Camon 50 Ultra → 5G → 512GB → 12GB`
- `Infinix → NOTE → Note 60 Ultra → 5G/4G → 512GB → 12GB`
- `itel → S → Super 26 Ultra → 4G → 256GB → 8GB`

## Variant-level fields

Each sellable variant must support:

- Brand
- Family
- Series
- Model
- Generation
- Network
- SIM configuration
- Storage
- RAM
- Colour
- SKU
- IMEI
- Condition
- Battery health
- Warranty
- Supplier
- Purchase price
- Selling price
- Stock quantity
- Reserved quantity
- Available quantity
- Location/store
- Availability status

## Condition

Supported conditions:

- New
- Used
- Refurbished
- Open Box

## Inventory rule

A different:

- storage capacity
- RAM configuration
- network configuration
- SIM configuration

must be capable of being represented as a distinct commercial variant.

Colour should normally remain a variant attribute rather than creating a separate model.

## Customer-facing rule

Customers and normal business users should see simple names such as:

`Samsung Galaxy S26 Ultra 1TB`

`iPhone 17 Pro Max 512GB`

`Google Pixel 11 Pro XL 512GB`

`TECNO Camon 50 Ultra 512GB`

The Business Experience must not expose database IDs, API terminology, developer terminology, internal architecture or other technical implementation details.

## Public website rule

The future public website, Business Experience, POS and inventory system must use the same product source of truth.

The website should display only products marked as:

`Published + Available`

while the internal inventory may contain products that are:

`Draft + Out of Stock + Discontinued + Archived`

# 9. VERIFICATION & DATA GOVERNANCE

This document is the catalogue baseline, not a claim that every listed variant is physically stocked in Uganda.

Before a product is made purchasable online or shown as **Available in Uganda**, verify:

1. Official model name.
2. Official storage.
3. Official RAM/memory.
4. Network configuration.
5. Regional model/SKU.
6. Uganda distributor/importer availability.
7. Warranty applicability.
8. Actual purchase cost.
9. Selling price.
10. Physical stock.

Never create a fictional variant merely to fill a catalogue.

If an official manufacturer source and local commercial source disagree, keep the manufacturer specification as the technical source of truth and record the Uganda commercial availability separately.
